IMAGE FOLDER
============

Recommended folder:
assets/images/

The website accepts PNG, JPG, JPEG, WEBP, GIF and SVG.
You only need to write the base filename in assets/js/data.js.
Example:
    image: 'galeri-06'

The loader will also look in /images/ and the same folder as the HTML file.
So these all work when the base name is galeri-06:
    assets/images/galeri-06.png
    assets/images/galeri-06.jpg
    images/galeri-06.webp
    galeri-06.jpg

Keep the filename and extension simple; avoid special characters.
